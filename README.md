# Build Real World AI Applications with Gemini and Imagen

This repository contains Python scripts developed for the Google Cloud course **"Build Real World AI Applications with Gemini and Imagen"**. The course explores using Gemini models for text and image generation, analysis, and streaming conversations.

## Contents

- `task1_generate.py` – Generates an image using the Imagen model based on a user prompt.
- `task2_analyze.py` – Analyzes a generated image and provides captions using the Gemini image-to-text model.
- `chat_streaming.py` – Streams a response from the Gemini 2.0 Flash model to simulate real-time interaction.
